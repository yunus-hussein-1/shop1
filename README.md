# SHAYEB SHOP — شايب شوب

متجر إلكتروني (سوق متعدد البائعين) مبني بلغة Python باستخدام Flask.

## 1) التشغيل محلياً (تجربة على جهازك)

```bash
cd shayeb_shop
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt

python seed.py                  # يجهز قاعدة البيانات + التصنيفات + حساب أدمن + متجر تجريبي
python app.py
```

افتح المتصفح على: http://127.0.0.1:5000

## 🔄 تحديث قاعدة البيانات مستقبلاً (Migrations)

الموقع بيستخدم **Flask-Migrate** لإدارة أي تغيير بجداول قاعدة البيانات — يعني **ما في داعي تحذف `shayeb.db` يدوياً بعد اليوم**. كل ما تسحب تحديث جديد فيه تغيير بقاعدة البيانات، الموقع بيطبّقه تلقائياً أول ما تشغّله (`python app.py` أو `python seed.py`).

إذا حبيت تعمل تغيير بموديلات قاعدة البيانات بنفسك مستقبلاً:
```bash
flask db migrate -m "وصف التغيير"
flask db upgrade
```

بيانات دخول الأدمن التجريبية (**لازم تغيّرها فوراً من صفحة الإعدادات بعد أول دخول**):
- الإيميل: القيمة يلي حاطاها بـ `ADMIN_EMAIL` بملف `config.py`
- كلمة السر المؤقتة: اطبعها ليك `seed.py` بالترمنال عند أول تشغيل (كل مرة كلمة سر مختلفة إذا حذفت قاعدة البيانات)

## 2) قبل الإطلاق الحقيقي — تشيك ليست إلزامية

- [ ] غيّر `SECRET_KEY` بمتغير بيئة عشوائي وطويل (مو القيمة الافتراضية بالكود).
- [ ] غيّر `ADMIN_EMAIL` بإيميلك الحقيقي، وسجل دخول وغيّر كلمة سر الأدمن فوراً.
- [ ] احذف حساب البائع التجريبي (`demo@shayebshop.com`) والمنتجات التجريبية من `seed.py` قبل الإطلاق.
- [ ] فعّل `MAIL_USERNAME` / `MAIL_PASSWORD` (App Password حقيقي) عشان يشتغل إرسال كود استعادة كلمة السر فعلياً.
- [ ] فعّل `FORCE_HTTPS=1` بعد ما يصير عندك شهادة SSL حقيقية (كل استضافة جدية بتوفرها تلقائياً).
- [ ] راجع وحدّث أسعار الصرف بـ `EXCHANGE_RATES_PER_USD` بشكل دوري.
- [ ] بدّل قاعدة البيانات من SQLite إلى PostgreSQL عند الانتقال للإنتاج (أكثر ثباتاً مع عدد مستخدمين أكبر).
- [ ] لا تشغّل التطبيق بـ `debug=True` على الإنتاج أبداً.

## 3) النشر على Render (خطوة بخطوة)

1. سجّل حساب مجاني على render.com وسجّل دخول بحساب GitHub تبعك.
2. من اللوحة الرئيسية: **New +** → **Web Service**.
3. اختر مستودع `shop1` (نفس هاد الكود).
4. اضبط الإعدادات:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app --bind 0.0.0.0:$PORT`
5. من تبويب **Environment**، ضيف المتغيرات التالية (قيم حقيقية منك، مو القيم الافتراضية بالكود):
   - `SECRET_KEY` → قيمة عشوائية طويلة
   - `ADMIN_EMAIL` → إيميلك الحقيقي
   - `MAIL_USERNAME` و `MAIL_PASSWORD` → لو بدك تفعّل إرسال إيميل حقيقي
   - `FORCE_HTTPS` → `1`
6. اضغط **Create Web Service**. أول نشر بياخد كم دقيقة.
7. بعد ما يخلص، رح ياخد موقعك رابط مجاني شكله: `shop1.onrender.com`. من هناك فيك تربطه بدومين حقيقي (`shayebshop.com`) من تبويب **Custom Domains**.

**ملاحظات مهمة عن الخطة المجانية بـ Render:**
- الموقع "بينام" بعد 15 دقيقة بدون زيارات، وأول زيارة بعدها بتاخد 30-60 ثانية لين يصحى (طبيعي، مو خطأ).
- قاعدة بيانات SQLite على القرص المجاني ممكن تنمسح مع كل نشر جديد للكود. لما يصير عندك زبائن حقيقيين، لازم تنقل لقاعدة بيانات دائمة (Render بيوفر PostgreSQL كخدمة منفصلة) — خبرني لما توصل لهاي المرحلة وبساعدك فيها.

## 4) بدائل تانية للنشر

**Railway** أو **PythonAnywhere** بيشتغلوا بنفس الفكرة تقريباً (ربط GitHub، ضبط أوامر البناء والتشغيل، متغيرات بيئة).

## 5) الميزات المُنفَّذة بهاي النسخة (Phase 1)

- تسجيل حساب / دخول / خروج، ونسيت كلمة السر بكود عبر الإيميل، ومكان جاهز لتسجيل الدخول عبر جوجل.
- ملف شخصي: الاسم، الإيميل، الهاتف، تاريخ الميلاد + عناوين متعددة.
- إعدادات: تغيير كلمة السر، حذف الحساب نهائياً.
- تصنيفات: رجالي / نسائي / أطفال / إلكتروني + قسم "جديد" و"عروض شايب".
- تعدد لغة (عربي/إنجليزي/تركي) وربط تلقائي بالعملة (ليرة سوري/دولار/ليرة تركية).
- سلة شراء، إتمام شراء، دفع عبر شام كاش (رقم عملية + إيصال) بتحقق يدوي من الإدارة.
- تتبع الطلب، تقييمات على المنتجات المشتراة فعلياً.
- "بيع على شايب": تقديم طلب متجر، موافقة/رفض من الإدارة، إضافة منتجات بصور حقيقية وعروض.
- عمولة 10% تُحسب تلقائياً، وتحويل مستحقات للبائع بعد 7 أيام (حقل حالة جاهز للتفعيل مع نظام دفع فعلي).
- لوحة إدارة: قبول/رفض متاجر، حظر مستخدمين/متاجر، تأكيد أو رفض إثبات الدفع.
- صفحات: من نحنو، الشروط والأحكام، سياسة الخصوصية، سياسة الإرجاع، اتفاقية البائع.
- بحث بالكلمة + بداية بحث بالصورة (أساس جاهز للتطوير لاحقاً بميزة ذكاء اصطناعي حقيقية).

- صور حقيقية للمحل + رقم ضريبي إلزاميين عند طلب "بيع على شايب"، وموقع "متجري" صار داخل الإعدادات بدل الشريط العلوي.
- صورة بروفايل شخصية بواجهة أنيقة (رفع من الجوال مع معاينة فورية).
- وضع ليلي/نهاري تلقائي بالكامل (حسب توقيت جهاز الزائر أو إعداد الجهاز)، بدون أي زر تبديل يدوي.
- أيقونة 📍 بجانب كل عنوان تفتح خرائط جوجل مباشرة (بدون الحاجة لمفتاح API).
- تغيير الإيميل صار من صفحة الإعدادات مباشرة.
- العملة موحّدة ليرة سوري بكل اللغات، والدفع دائماً عبر شام كاش.
- تصميم متجاوب بالكامل (موبايل + لابتوب) مع قائمة هامبرغر بالموبايل.

## 7) ميزات تحتاج تفعيل/تطوير إضافي قبل الاعتماد الكامل عليها

- **البحث بالصورة**: حالياً نسخة أساسية، المطابقة الذكية الحقيقية تحتاج مرحلة تالية.
- **تسجيل الدخول بجوجل**: يحتاج بيانات اعتماد Google OAuth حقيقية.
- **إرسال إيميلات حقيقي**: يحتاج بيانات SMTP حقيقية (Gmail App Password أو خدمة مثل SendGrid).
- **تحويل مستحقات البائعين تلقائياً لشام كاش**: شام كاش ما عندها API عام معروف، فالتحويل الفعلي حالياً يدوي من طرف الإدارة (الحقول والحالة جاهزين بالنظام).
