# SHAYEB SHOP — شايب شوب

متجر إلكتروني (سوق متعدد البائعين) مبني بلغة Python باستخدام Flask.

## 1) التشغيل محلياً (تجربة على جهازك)

```bash
cd shayeb_shop
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt

python -c "from app import create_app; from extensions import db; app=create_app(); app.app_context().push(); db.create_all()"
python seed.py                  # يجهز التصنيفات + حساب أدمن + متجر تجريبي

python app.py
```

افتح المتصفح على: http://127.0.0.1:5000

بيانات دخول الأدمن التجريبية (**لازم تغيّرها فوراً**):
- الإيميل: القيمة يلي حاطاها بـ `ADMIN_EMAIL` بملف `config.py`
- كلمة السر المؤقتة: `ChangeMe123!`

## 2) قبل الإطلاق الحقيقي — تشيك ليست إلزامية

- [ ] غيّر `SECRET_KEY` بمتغير بيئة عشوائي وطويل (مو القيمة الافتراضية بالكود).
- [ ] غيّر `ADMIN_EMAIL` بإيميلك الحقيقي، وسجل دخول وغيّر كلمة سر الأدمن فوراً.
- [ ] احذف حساب البائع التجريبي (`demo@shayebshop.com`) والمنتجات التجريبية من `seed.py` قبل الإطلاق.
- [ ] فعّل `MAIL_USERNAME` / `MAIL_PASSWORD` (App Password حقيقي) عشان يشتغل إرسال كود استعادة كلمة السر فعلياً.
- [ ] فعّل `FORCE_HTTPS=1` بعد ما يصير عندك شهادة SSL حقيقية (كل استضافة جدية بتوفرها تلقائياً).
- [ ] راجع وحدّث أسعار الصرف بـ `EXCHANGE_RATES_PER_USD` بشكل دوري.
- [ ] بدّل قاعدة البيانات من SQLite إلى PostgreSQL عند الانتقال للإنتاج (أكثر ثباتاً مع عدد مستخدمين أكبر).
- [ ] لا تشغّل التطبيق بـ `debug=True` على الإنتاج أبداً.

## 3) النشر (استضافة حقيقية)

يدعم مشاريع Flask بسهولة: **Render** أو **Railway** أو **PythonAnywhere**.
خطوات عامة:
1. ارفع الكود على GitHub.
2. اربط حساب الاستضافة بالمستودع.
3. حط متغيرات البيئة (`SECRET_KEY`, `ADMIN_EMAIL`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `DATABASE_URL`, ...) من لوحة تحكم الاستضافة، وليس داخل الكود.
4. اربط دومين `shayebshop.com` (تشتريه من Namecheap أو مشابه).

## 4) الميزات المُنفَّذة بهاي النسخة (Phase 1)

- تسجيل حساب / دخول / خروج، ونسيت كلمة السر بكود عبر الإيميل، ومكان جاهز لتسجيل الدخول عبر جوجل.
- ملف شخصي: الاسم، الإيميل، الهاتف، تاريخ الميلاد + عناوين متعددة.
- إعدادات: تغيير كلمة السر، حذف الحساب نهائياً.
- تصنيفات: رجالي / نسائي / أطفال / إلكتروني + قسم "جديد" و"عروض شايب".
- تعدد لغة (عربي/إنجليزي/تركي) وربط تلقائي بالعملة (ليرة سوري/دولار/ليرة تركية).
- سلة شراء، إتمام شراء، دفع عبر شام كاش (رقم عملية + إيصال) بتحقق يدوي من الإدارة.
- تتبع الطلب، تقييمات على المنتجات المشتراة فعلياً.
- "بيع على شايب": تقديم طلب متجر، موافقة/رفض من الإدارة، إضافة منتجات بصور حقيقية وعروض.
- عمولة 10% تُحسب تلقائياً، وتحويل مستحقات للبائع بعد 7 أيام (حقل حالة جاهز للتفعيل مع نظام دفع فعلي).
- لوحة إدارة: قبول/رفض متاجر، حظر مستخدمين/متاجر، تأكيد أو رفض إثبات الدفع.
- صفحات: من نحنو، الشروط والأحكام، سياسة الخصوصية، سياسة الإرجاع، اتفاقية البائع.
- بحث بالكلمة + بداية بحث بالصورة (أساس جاهز للتطوير لاحقاً بميزة ذكاء اصطناعي حقيقية).

## 5) ميزات تحتاج تفعيل/تطوير إضافي قبل الاعتماد الكامل عليها

- **البحث بالصورة**: حالياً نسخة أساسية، المطابقة الذكية الحقيقية تحتاج مرحلة تالية.
- **تسجيل الدخول بجوجل**: يحتاج بيانات اعتماد Google OAuth حقيقية.
- **إرسال إيميلات حقيقي**: يحتاج بيانات SMTP حقيقية (Gmail App Password أو خدمة مثل SendGrid).
- **تحويل مستحقات البائعين تلقائياً لشام كاش**: شام كاش ما عندها API عام معروف، فالتحويل الفعلي حالياً يدوي من طرف الإدارة (الحقول والحالة جاهزين بالنظام).
